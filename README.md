# claude-projects

Projects built with Claude. Each project lives in its own folder.

| Folder | What it is |
|---|---|
| `crab-report/` | Rob's Crab Report: shore crabbing forecast, spots and catch log for the Northern California coast. Static site served by GitHub Pages. Forecast data in `crab-report/data/forecast.json` is refreshed daily by `.github/workflows/crab-forecast.yml` (run it by hand from the Actions tab). |
